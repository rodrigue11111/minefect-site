# Organisation des images (Minefect)

Tu peux remplacer n’importe quelle image en gardant le même nom de fichier (le site se mettra à jour sans modifier le code).

## Dossiers

- `assets/images/ui/` : logo, éléments d’interface
- `assets/images/heroes/` : bannières (images de header) des pages
- `assets/images/textures/` : textures/fonds
- `assets/images/categories/` : cartes des catégories (page Produits)
- `assets/images/products/` : images des produits (catalogue)
- `assets/images/sectors/` : images des secteurs (page Secteurs)
- `assets/images/placeholders/` : images de secours si un fichier manque

## Fichiers clés

- Logo : `assets/images/ui/logo.png`
- Placeholders : `assets/images/placeholders/product.png`, `assets/images/placeholders/category.png`, `assets/images/placeholders/sector.png`
